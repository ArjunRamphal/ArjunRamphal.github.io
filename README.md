**Live Demo:** [https://ArjunRamphal.github.io](https://ArjunRamphal.github.io)

## Tech Stack

* **Framework:** React (via Vite)
* **Styling:** Tailwind CSS
* **Deployment:** GitHub Pages

## Projects

This portfolio highlights several key projects contained in my GitHub:

* **Stationery POS System:** A C#/.NET retail management solution with SQL integration.
* **DND Trading Website:** A front-end web component for a retail business.
* **Dungeon Descent:** A C++/SFML game blending dungeon crawling with narrative, timed riddles and branching endings.
* **Notely & Bookly:** Modern Android applications built with Kotlin and Jetpack Compose.
* **Smart Home Appliance Identification (COMP700):** Honours research comparing neural models and Random Forest for ten IoT appliance classes using network-traffic features, SHAP explanations and LiteRT CPU profiling.
* **Soil Moisture Monitoring & Watering Guidance (COMP717A):** An IoT group project with Arduino, Raspberry Pi, and a Flask dashboard for live readings, dry-soil alerts, and water-quantity guidance for manual watering.

Project cards show known dates and include an oldest/newest sorting control. The default order is oldest to newest. Smart Home Appliance Identification runs from **March to October 2026** and sorts after Notely and Bookly. COMP717 remains last in the default order.

Notely and Bookly are marked **Present**. Their first recorded source commits are used only for chronological placement when no start month has been supplied.

Cards open project detail dialogs with context, involvement, features, documented outcomes and full-size project images. Team descriptions follow the repositories' author lists; they do not assign individual modules where responsibilities are undocumented.

The page includes navigation anchors, a direct email contact section, a single CV chooser, and metadata for search and social previews. `public/social-preview.svg` is the editable source for the 1200×630 PNG sharing image.

Card thumbnails use resized WebP files in `src/images/thumbnails/`. Original images remain available in project detail views. The KTH action-example SVG and the main COMP717 monitoring-panel image are retained.

## Image credits

The Human Action Recognition card uses six real sample frames from the [KTH Human Action Database](https://www.csc.kth.se/cvap/actions/), arranged in a labelled 3×2 grid. The labels identify dataset classes, rather than new model predictions.

Dataset reference: Christian Schuldt, Ivan Laptev and Barbara Caputo, *Recognizing Human Actions: A Local SVM Approach*, ICPR 2004. KTH provides the dataset for non-commercial use. Frame source URLs and timestamps are retained in the SVG metadata.

The Smart Home Appliance Identification card and detail image use Figure 5 from the [COMP700 thesis](https://github.com/ArjunRamphal/smart-home-appliance-identification-using-deep-learning/blob/master/thesis/COMP700_Thesis.pdf), co-authored by Arjun Ramphal and Darian Robert. The original comparison chart is rendered directly from page 15 without changing its data or labels.
